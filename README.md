# 🎰 拉霸機 Web App — 資料庫期末專案

一個以 **Node.js + Express + SQLite** 打造的全端拉霸機遊戲，支援玩家註冊、登入、下注、自動旋轉、以及即時排行榜功能。

---

## 專案簡介

本專案為大學資料庫課程期末作業，實作一套完整的前後端連結系統。玩家可透過瀏覽器進行拉霸機遊戲，所有玩家資料、餘額、以及拉霸機選項（符號機率與獎金）均存放於 SQLite 資料庫，並透過 RESTful API 與前端即時溝通。

---

## 功能特色

- **玩家系統**：註冊、登入（帳號密碼驗證），初始贈送 10,000 元虛擬金幣
- **拉霸機玩法**：每次隨機從資料庫抽取 3 個符號，依組合計算獎金
- **獎金機制**：
  - 出現 1 個相同符號 → win1 獎金
  - 出現 2 個相同符號 → win2 獎金
  - 出現 3 個相同符號（Jackpot）→ jakapot 獎金
  - 下注倍數：下注金額 ÷ 100 = 獎金倍率
- **可調整下注金額**：最低 100，可手動輸入或點擊加減調整
- **自動旋轉模式**：一鍵開啟連續旋轉，餘額不足時自動停止
- **即時排行榜**：依盈餘（剩餘金額 − 10,000）由高到低顯示前五名

## 資料庫設計

### 玩家資料表
| 欄位 | 說明 |
|------|------|
| 玩家ID | 唯一識別碼（自動產生） |
| 玩家名稱 | 顯示名稱 |
| 帳號 | 登入帳號（唯一） |
| 密碼 | 登入密碼 |
| 剩餘金額 | 玩家目前持有金幣 |

### 拉霸機選項
| 欄位 | 說明 |
|------|------|
| 物件名稱 | 符號名稱（蘋果、香蕉、跑車...） |
| 數量 | 在輪盤中的出現權重（數量越多機率越高） |
| win1 | 出現 1 次的基礎獎金 |
| win2 | 出現 2 次的基礎獎金 |
| jakapot | 出現 3 次的頭獎獎金 |

## 安裝與執行

### 環境需求
- Node.js v18 以上

### 步驟

```bash
# 1. 複製專案
git clone https://github.com/your-username/slot-machine-webapp.git
cd slot-machine-webapp

# 2. 安裝相依套件
npm install

# 3. 啟動伺服器
node app.js

# 4. 開啟瀏覽器前往
# http://localhost:3000
```

> 注意：`期末專案.db` 需存在於專案根目錄，否則資料庫會初始化為空白。

## API 一覽

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/items` | 取得所有拉霸機符號與獎金資料 |
| POST | `/api/register` | 玩家註冊 |
| POST | `/api/login` | 玩家登入 |
| POST | `/api/get_balance` | 查詢特定玩家餘額 |
| POST | `/api/update_balance` | 更新玩家餘額（扣注碼或派獎） |
| GET | `/api/spin` | 從資料庫隨機抽取 3 個符號 |
| GET | `/api/rank` | 取得所有玩家資料（前端計算排行） |

| 檔案 | 用途 |
|---|---|
| `tools/pptx_dump.py <file> [頁碼...]` | 每個非空 shape 輸出一行，表格逐格輸出，只列指定頁 |
